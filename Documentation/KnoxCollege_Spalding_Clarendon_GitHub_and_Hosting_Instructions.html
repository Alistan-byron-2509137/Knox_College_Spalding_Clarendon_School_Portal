GitHub and free hosting instructions

Status: nothing in this guide has been done yet. No repository was created and the site is not hosted. The links in your report are placeholders until you complete these steps yourself.

The assignment needs a GitHub repository link and a free hosting link in your report PDF. A computer is easiest for these steps. Menu names on GitHub change from time to time, so follow the on-screen wording if it differs slightly.

Before you begin

  • Unzip the project ZIP. You should see one folder named Knox_College_Spalding_Clarendon_School_Portal containing index.html, the other pages, and the folders CSS, JavaScript, Assets, Documentation, plus README.md.
  • Do not rename any file. Web addresses are case-sensitive on GitHub Pages, and every link in the project uses the exact file names.
  • index.html must sit at the top of the repository, not inside another folder.

Part 1. Create the GitHub repository

  1. Go to github.com and sign up (or sign in).
  2. Click New (or the + menu > New repository).
  3. Repository name: knox-college-spalding-clarendon-school-portal (or any name you like, with no spaces).
  4. Choose Public. Leave “Add a README” unticked (the project already has one). Click Create repository.

Part 2. Upload your files

Option A: upload in the browser (no extra software)

  1. On the new empty repository page, click uploading an existing file.
  2. Open the unzipped folder on your computer, select everything inside it (index.html, the other .html files, README.md and the CSS, JavaScript, Assets and Documentation folders) and drag it into the GitHub page. Do not drag the outer folder itself.
  3. Wait for the upload to finish, write a short message such as “Add Knox College School Portal”, and click Commit changes.
  4. Check the repository page: index.html and the four folders must be visible at the top level.

Option B: Git commands (if Git is installed)

cd Knox_College_Spalding_Clarendon_School_Portal
git init
git add .
git commit -m "Add Knox College School Portal"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/knox-college-spalding-clarendon-school-portal.git
git push -u origin main

Replace YOUR-USERNAME with your GitHub username. GitHub may ask you to sign in or use a personal access token.

Your repository link is the address in the browser bar: https://github.com/YOUR-USERNAME/knox-college-spalding-clarendon-school-portal

Part 3. Publish with GitHub Pages (free hosting)

  1. In your repository click Settings, then Pages in the left menu.
  2. Under Build and deployment, set Source to Deploy from a branch.
  3. Set Branch to main and the folder to / (root). Click Save.
  4. Wait one to two minutes and refresh the Pages screen. A line appears: Your site is live at… The address looks like https://YOUR-USERNAME.github.io/knox-college-spalding-clarendon-school-portal/
  5. That address is your free hosting link.

Part 5. Put the links in your report

  1. Open Documentation/KnoxCollege_Spalding_Clarendon_Project_Report.html in Google Chrome.
  2. Paste your GitHub link and your hosting link into the yellow box at the top.
  3. Press Print / Save as PDF and choose Save as PDF. Save it in the Documentation folder. The two links in Section 8 are now clickable in the PDF.
  4. Check that the PDF shows your real links and no red placeholders.
  5. Submit the ZIP and the PDF as your tutor asks.

Other free hosting you could use

  • Netlify Drop: sign in, then drag the project folder onto the drop area on app.netlify.com/drop. Netlify gives you a link.
  • Cloudflare Pages or Vercel can also host a static site from a GitHub repository for free.
