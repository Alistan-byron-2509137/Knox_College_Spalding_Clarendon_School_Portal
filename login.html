Limits of a simulated front-end login

This login only pretends to be secure. It is a front-end simulation made with HTML, CSS and JavaScript, with no server.

  • The usernames and passwords are stored in the browser as plain text. Anyone can read them with the developer tools.
  • The dashboards check the saved role in the browser. A person who knows how to edit browser storage could change their role.
  • There is no password hashing, no account lockout and no secure session. The session is only a note in sessionStorage that disappears when the tab closes.
  • Real systems check passwords on a server, store them hashed and send data over HTTPS.
